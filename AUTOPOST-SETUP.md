# Автопостинг новых авто в Telegram и VK

Новые машины публикуются автоматически, когда вы обновляете каталог и пушите
в GitHub: админка → «Экспорт cars.js» → заменить файл → `git push`. GitHub Action
[`.github/workflows/post-new-cars.yml`](.github/workflows/post-new-cars.yml)
находит новые записи и постит их в канал и группу.

## Как это работает

1. Action срабатывает на push, если изменился `cars.js`.
2. Скрипт [`scripts/post-new-cars.mjs`](scripts/post-new-cars.mjs) сравнивает текущий
   каталог со списком уже опубликованных (`.github/posted-cars.json`) и постит только новые авто.
3. **Первый запуск** ничего не постит — он лишь помечает весь текущий каталог как
   «уже опубликованный», чтобы не разослать разом все 26 машин. Постятся только те,
   что добавите потом.

## Что нужно настроить (один раз)

### Telegram
1. Создайте бота у **@BotFather** → получите **токен**.
2. Добавьте бота **администратором** канала [@DIVANAUTO](https://t.me/DIVANAUTO) с правом публикации.
3. `TELEGRAM_CHAT_ID` = `@DIVANAUTO` (публичный) или числовой id канала.

### VK
1. Токен сообщества с правом **wall** (Управление сообществом → Работа с API → создать ключ).
2. `VK_OWNER_ID` = **минус** id сообщества, например `-298313372`.

### Положить секреты в GitHub
Repo → **Settings → Secrets and variables → Actions → New repository secret**, добавьте:

| Имя | Значение |
|-----|----------|
| `TELEGRAM_BOT_TOKEN` | токен бота |
| `TELEGRAM_CHAT_ID` | `@DIVANAUTO` |
| `VK_TOKEN` | токен сообщества VK |
| `VK_OWNER_ID` | `-298313372` |

Секреты видите только вы — в коде их нет, мне не присылайте.
Если задать только Telegram-секреты — постится лишь Telegram; VK можно добавить позже.

## Важно про фото

Telegram и VK берут фото **по ссылке**. Если у авто фото загружено в админке как
локальное (data URL) — картинка не уйдёт, отправится текст со ссылкой на карточку.
Чтобы фото публиковалось: кладите файлы в папку `img/`, коммитьте, и указывайте в
поле фото путь вида `https://sergeilob5-source.github.io/img/файл.jpg`.

## Проверка

После настройки: добавьте одно тестовое авто → экспорт cars.js → push. Во вкладке
**Actions** увидите запуск, в канале/группе — пост. Первый push после появления
workflow только зафиксирует текущий список (постов не будет) — это нормально.

## Ручной запуск

Вкладка **Actions → Post new cars → Run workflow** — можно дёрнуть вручную.
