# Вихляев Авто

Лендинг и каталог сервиса заказа автомобилей и мотоциклов из Японии, Кореи и Китая под ключ.

## Структура

- `index.html` — главная (герой, преимущества, этапы, калькулятор растаможки, FAQ, отзывы, контакты, лид-форма)
- `catalog.html` — каталог авто с фильтрами, поиском, сортировкой и детальной карточкой
- `cars.js` — датасет автомобилей (характеристики — фактические, цены ориентировочные)
- `styles.css` — оформление
- `script.js` — навигация, аккордеоны, модальная лид-форма, калькулятор
- `catalog.js` — логика каталога

Статический сайт — только HTML/CSS/JS, без сборки.

## Локальный запуск

```bash
python -m http.server 8124
```

Затем открыть http://localhost:8124/

## Что заменить перед продакшеном

- Телефоны, имена менеджеров, email, адрес, ссылки на соцсети
- Курсы валют и таможенные ставки в `script.js` (`RATES`, `customsDuty`, `utilFee`) — сейчас демо
- Отправку лид-формы подключить к бэкенду/CRM (сейчас пишет в `console.log`)
- Фото автомобилей: положить в `img/` и указать путь в поле `photo` в `cars.js`
