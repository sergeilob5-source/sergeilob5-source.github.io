# Бэкенд обратной связи (Google Apps Script)

Бесплатный приём отзывов с любого устройства в вашу Google-таблицу. Без карты и хостинга.

## Шаги настройки (5 минут)

1. Откройте новую таблицу: перейдите на **https://sheets.new** (создастся пустая Google-таблица).
2. Меню **Расширения → Apps Script**.
3. Удалите весь код в редакторе, вставьте содержимое файла `Code.gs` из этой папки. Сохраните (Ctrl+S).
4. Нажмите **Развернуть → Новое развёртывание**.
5. Шестерёнка «Выберите тип» → **Веб-приложение**.
6. Настройки:
   - **Описание**: любое (например, «feedback»)
   - **Запуск от имени**: Я (ваш аккаунт)
   - **У кого есть доступ**: **Все** (Anyone)
7. **Развернуть** → подтвердите доступ (Authorize) для своего Google-аккаунта.
8. Скопируйте **URL веб-приложения** — вида
   `https://script.google.com/macros/s/AKfycb.../exec`

## Что дальше

Вставьте этот URL в файл `config.js` в корне сайта:

```js
window.FEEDBACK_ENDPOINT = 'https://script.google.com/macros/s/AKfycb.../exec';
```

Закоммитьте и запушьте — форма обратной связи начнёт писать отзывы в таблицу
со всех устройств. Отзывы видны:
- вам — прямо в Google-таблице (лист «feedback»);
- разработчику — по тому же URL (GET возвращает все отзывы в JSON).

## Обновление кода скрипта

Если меняете `Code.gs` — в Apps Script снова **Развернуть → Управление развёртываниями →
карандаш → Новая версия → Развернуть**. URL остаётся прежним.
